## Bloc 2 — Strings & write (Piscine 42)

### 🎯 Objectif
Comprendre la manipulation des chaînes de caractères en C (`char *`) et l’affichage sans `printf`.

### 📌 Consignes
- utiliser **uniquement `while`**
- **pas de `printf`** dans les fonctions
- utiliser **`write`** pour l’affichage
- code simple, lisible, sans effet de bord inutile

### 🧩 Exercices
- `ft_putchar` : afficher un caractère avec `write`
- `ft_putstr` : afficher une chaîne de caractères
- `ft_strlen` : retourner la longueur d’une chaîne

### 🧠 Compétences travaillées
- parcours de chaînes jusqu’à `'\0'`
- différence entre pointeur et valeur
- fonctions utilitaires sans affichage direct

> Bloc réalisé dans le cadre de la préparation à la Piscine 42.
